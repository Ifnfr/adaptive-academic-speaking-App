# Adaptive Academic Speaking APP

## Goal
Personal AI speaking coach web app based on Blueprint V1.5.

## Stack
- Next.js
- TypeScript
- Tailwind
- localStorage
- Claude API
- DeepSeek API
- Gemini API

## MVP Scope
- Session setup
- Speaking attempt
- AI feedback
- Retry task
- CSV export
- Weakness activation

## Not In MVP
- Auth
- Database cloud
- Deployment
- Mobile app
- Advanced RAG

## Workflow
ChatGPT = manager
Kiro = main builder
Codex = helper/debugger
Gemini = prompt tester
